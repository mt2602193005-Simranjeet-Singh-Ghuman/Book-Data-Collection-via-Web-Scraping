Written by Perl programmers for Perl programmers, this resource is organized in an encyclopedic format, with thumbtabs, for easy access to all aspects of Perl. It features all the new and changed functions in Perl 5 as well as Perl 4 functions carried over. The book offers common programming techniques for Perl on a function-by-function basis. The CD includes a hypertext version of the book, EarthLink TotalAccess Internet connection package with Netscape Navigator, and code samples and shareware.
