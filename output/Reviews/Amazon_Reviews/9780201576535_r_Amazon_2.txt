Reviewer: Sushant Jha Nice approach to teach programming. Doesn't tell details of history or development of C (which I don't think should be there in a programming book), but the programs used are pretty good. One of the downsides is that the book uses VERY old libraries (like <graphics.h>) which have been discarded by most of the new compilers. You will need Turbo C++ or a similar compiler to run all the programs as it is. Newer ones (like code::blocks) would show error. Read less
