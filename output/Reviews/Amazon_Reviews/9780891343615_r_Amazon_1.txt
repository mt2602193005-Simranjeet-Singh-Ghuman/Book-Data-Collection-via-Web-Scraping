Reviewer: nebulousPioneer When I first got this book, it was in my local library and I have not loved another drawing book since. Granted; I am not an 'artist' by definition by any means, but I wanted to take up something different that I haven't done before and I ended up loving drawing all the more with the knowledge this book provides. I mean, a few years passed since the last time I picked up this book from my local library; and I was not able to forget about this book, and ended up buying it because it was such a joy to learn how to draw better with this book. The illustrations are mostly black and white, but they are really helpful in showing you some of the methodologies as well as where charcoal drawing or pencil drawing can take you. It's fun, and I love that you can follow the book at your own pace. If you have thought about learning how to draw for the first time as a hobby, then this book is a great place to start concerning landscapes, water features, inanimate figures as well as humans near the end of the book. This is a great book that I think will stay with me for a very long time, because it's worth it! : ) Read less
